## شیوه ممیزی
1. ابتدا `FILES_SHA256.csv` را بخوانید و هر فایل را از URL خام GitHub جداگانه دریافت کنید.
2. اگر امکان بررسی SHA-256 ندارید، صرفاً دسترسی/خواندن را تأیید کنید؛ مدعی تطبیق هش نشوید.
3. هر فایل را با نام، مسیر، تابع و شماره خط بررسی کنید؛ نقد و پاسخ مستقل باید جدا از متن اصلی باشد.
4. نتایج ممیزی را به‌صورت رسید مرحله‌ای نگه دارید؛ از حدس‌زدن درباره فایل‌هایی که دیده نشده‌اند خودداری کنید.
5. دسترسی به این کد به‌معنای دسترسی به کل آرشیو ۷۷ فایل یا داده واقعی بروکر نیست.
